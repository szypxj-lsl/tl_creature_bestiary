# 生物图鉴拓展 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不把图鉴业务塞进 TDMC 的前提下，为 TDMC 增加稳定的基础属性/驯服/望远镜/UI 扩展 API，并交付独立附属模组 `tl_creature_bestiary`，实现 1～9 星危险度、望远镜持续扫描解锁、每玩家图鉴存档、基础三维图和动态驯服资料。

**Architecture:** TDMC 只提供“第一次 TDMC 加成前的基础属性快照”、类型级基础资料、驯服资料、望远镜标题/扫描扩展点与面板动作入口；`tl_creature_bestiary` 自己负责危险度、扫描解锁数据、独立网络、客户端缓存和图鉴 GUI。扫描采用“客户端只上报候选目标 + 服务器每 Tick 验证当前使用状态/距离/视线/准星命中”的服务端权威状态机，不每 Tick 发网络包。

**Tech Stack:** Java 17、Minecraft 1.20.1、Forge 47.4.10、Parchment 2023.09.03-1.20.1、Forge SimpleChannel、玩家 PersistentData、Forge 事件总线、TDMC 现有 `TdmcButton` / `SpyglassRadarMath` / `TamingRuleManager`。

**Spec:** `docs/superpowers/specs/2026-09-04-creature-bestiary-extension-design.md`

## Global Constraints

- Minecraft 固定为 `1.20.1`，Forge 固定为 `47.4.10`，Java 固定为 `17`。
- 新模组：`tl_creature_bestiary`，包名 `com.szypxj.tlcreaturebestiary`，初始版本 `1.0.0`。
- `tl_creature_bestiary` 对 `tl_domesticate_more_creatures` 为硬依赖；TDMC 不反向依赖图鉴附属。
- TDMC 协议版本常量保持现值，不改成动态版本；若追加 TDMC 包，只在现有消息表末尾追加固定 ID。
- 图鉴收录所有非玩家 `LivingEntity`，按 `EntityType` 注册 ID 唯一标识。
- 危险度只按“TDMC 第一次初始化前的 `MAX_HEALTH baseValue`”计算；外部模组在此前通过 `setBaseValue()` 的改动计入，TDMC 自身 Modifier 不计入。
- 危险度固定 1～9 星，阈值 `100 × 星级²`，8100 及以上封顶 9 星。
- 望远镜和图鉴始终显示 9 个星位；亮/暗星通过渲染色值控制，不把颜色码硬编码进 Java 可见文本。
- 扫描必须真正使用原版望远镜并连续对准同一实体约 20 Tick；服务端权威验证。
- 未解锁条目不得泄露名称、星级、驯服状态；搜索只匹配已解锁条目。
- 图鉴解锁按玩家、按世界保存；死亡、维度切换、退出重进保留；新世界重新收集。
- 图鉴三维图显示物种基础能力；现有望远镜三维图继续显示当前个体能力。
- 驯服资料动态读取 TDMC 当前规则，不固化进图鉴存档。
- 不每 Tick 遍历世界全部实体、不每 Tick 创建全部实体类型、不在渲染循环发包、不每 Tick 解析 `taming_rules.toml`。
- 未安装图鉴附属时 TDMC 原有属性面板、宠物面板、望远镜、骑乘、天赋、背包行为保持不变。
- 玩家可见新增文字全部走 I18N；不新增 `§7` / `§8`。

6. Advance progress; otherwise reset.
7. At exactly 20 valid ticks, call `SpyglassInspectionApi.fireCompleted(...)` once.

No world-wide entity iteration is allowed.
