生物图鉴拓展 1.0.0 游戏内验收清单
目标环境：Minecraft 1.20.1 / Forge 47.4.10 / TDMC 当前 API 支持版

一、危险程度与基础血量
[ ] 原版牛基础血量 10，望远镜和图鉴均显示 1 颗亮星 + 8 颗暗星。
[ ] 使用测试属性模组在 TDMC 初始化前把同一物种 MAX_HEALTH baseValue 改成 500，显示 2 星。
[ ] 在上一步基础上让 TDMC 最终最大生命提高到 900，仍然显示 2 星。
[ ] 外部模组只添加 MAX_HEALTH AttributeModifier、不改 baseValue，危险度仍按 baseValue 计算。
[ ] 400/900/1600/2500/3600/4900/6400/8100 阈值分别进入 2~9 星。
[ ] 超过 8100 仍封顶 9 星。

二、望远镜扫描
[ ] 只手持望远镜但不右键使用，不累计扫描。
[ ] 对同一只生物持续使用望远镜 19 Tick 后移开，不能解锁。
[ ] 移开后重新对准，必须重新累计完整 20 Tick。
[ ] 对同一只生物连续有效扫描 20 Tick，只首次录入一次。
[ ] 扫描过程中换成同物种另一只实体，计时重新开始。
[ ] 隔着完整方块观察，不能扫描成功。
[ ] 超过 TDMC 望远镜检查距离，不能扫描成功。
[ ] 对玩家观察，不能录入玩家。
[ ] 对被 TDMC 排除的非玩家 LivingEntity，仍能录入，并至少显示名字 + 九星危险度。
[ ] 停止使用望远镜后，服务器扫描状态被清空。

三、望远镜显示
[ ] 星级紧跟在生物名字右边，TDMC 等级显示在星级后面。
[ ] 始终显示 9 个星位；已达到星级亮起，剩余星位变暗。
[ ] 亮星是清楚的蓝白/白色，暗星仍可辨认但不抢眼。
[ ] 未安装生物图鉴拓展时，TDMC 原望远镜页面不出现空占位或异常间距。
[ ] 被 TDMC 排除的 LivingEntity 不显示无意义的等级、天赋、眩晕等栏目。

四、图鉴解锁与存档
[ ] A 玩家扫描的条目不会自动解锁给 B 玩家。
[ ] 玩家死亡后已发现条目保留。
[ ] 玩家换维度后已发现条目保留。
[ ] 退出服务器再进入后已发现条目保留。
[ ] 同一账号进入新世界时不会继承旧世界图鉴。
[ ] 已移除模组留下的旧 EntityType ID 不导致客户端崩溃。

五、图鉴主页面
[ ] TDMC 属性面板出现“生物图鉴”按钮，布局不遮挡原有按钮。
[ ] 图鉴“返回”回到进入前的 TDMC 页面，不直接关闭界面。
[ ] 页面保持 TDMC 深蓝、半透明、淡蓝悬停、字体阴影风格。
[ ] 左侧显示搜索框、条目列表以及已发现/总数量。
[ ] 未解锁条目只显示 ????，不显示真实名称、星级或驯服资料。
[ ] 输入未解锁生物的名称、英文名或注册 ID，搜索结果不会泄露对应条目。
[ ] 已解锁条目可通过本地化名称和注册 ID 搜索。

六、图鉴详情
[ ] 已解锁物种显示名称、九星危险度、力量/生命/速度三维图、可驯服状态、驯服食物。
[ ] 三维图使用基础属性，不随当前扫描到的个体 TDMC 等级变化。
[ ] 望远镜现有三维图仍显示当前个体能力，不被图鉴基础值替换。
[ ] 不可驯服物种显示“可驯服：否”，且不显示虚假食物。
[ ] 可驯服物种显示当前 TDMC 规则解析后的食物和数量。
[ ] 修改并重新载入 taming_rules.toml 后，不重新扫描，重新选择该物种即可看到最新驯服资料。

七、性能与网络
[ ] 长时间使用望远镜扫描时没有明显卡顿或持续增长的网络流量。
[ ] 图鉴关闭状态下不会每 Tick 遍历世界全部生物。
[ ] 图鉴页面滚动/搜索时不会不断创建实体实例。
[ ] 解锁一个物种只增量同步一个 ID；登录/重生/换维度才做完整解锁集合同步。

八、TDMC 回归
[ ] 未安装附属时 TDMC 可以正常启动。
[ ] 属性面板、宠物面板、背包、骑乘、天赋保持正常。
[ ] 当前掠影蓝白闪电尾迹和野兽狩猎子弹时间仍正常。
[ ] 当前骑乘重连恢复、A/D 纯转向、后退 50% 等修正仍正常。
